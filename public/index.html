      WORKSPACE GUIDE

      开始一次可追溯的提取

      1. 01
        导入相关资料

        将同一零件的采购技术条件、图纸等 PDF 一起上传。资料越完整，适用范围越容易核对。

      2. 02
        选择模型并开始提取

        Flash 支持文字与图像，推荐用于图纸和扫描件；当前 V4 Pro 流程仅分析可提取文字，图形与扫描区域需人工复核。后台通过 Pi Agent 执行提取技能。

      3. 03
        核对原文并导出

        展开每条要求的“原文依据”查看文件名、页码与摘录。优先复核含糊、冲突或识别不清的内容。

      服务配置

      请在项目的 .env 文件中配置 DeepSeek API 密钥，再启动服务。密钥仅由后端读取。上传的文档内容会发送至配置的模型接口。
